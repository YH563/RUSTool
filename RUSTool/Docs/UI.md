# 超声机械臂扫查系统 UI 设计文档

**版本**：V1.0
**适用框架**：Avalonia UI + MVVM
**文档状态**：初稿


## 一、引言

### 1.1 文档目的

本文档规范超声机械臂扫查系统的用户界面设计，涵盖**调试开发模式**与**临床应用模式**两大使用场景。系统基于 Avalonia UI 框架，采用 MVVM 设计模式实现界面与业务逻辑的分离。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **角色隔离** | 调试模式暴露全部数据与控制接口；临床模式极简、安全、触控友好 |
| **数据同源** | 两种模式共享同一后端仿真驱动与数据模型，确保行为一致 |
| **性能优先** | UI 渲染线程与物理仿真线程（1000Hz）严格分离，互不阻塞 |
| **安全第一** | 临床模式下屏蔽所有可能误触的调试入口，急停始终可及 |

### 1.3 整体架构

系统采用三层 MVVM 架构：

```
┌─────────────────────────────────────────────────────────────────┐
│  View（视图层）     │  AXAML 布局文件，仅负责界面呈现与用户交互 │
│─────────────────────┼───────────────────────────────────────────│
│  ViewModel（视图模型层）│  业务逻辑、命令、状态管理，无 UI 依赖  │
│─────────────────────┼───────────────────────────────────────────│
│  Model（模型层）     │  后端仿真驱动、机械臂通信、超声数据采集   │
└─────────────────────────────────────────────────────────────────┘
```

View 通过数据绑定获取 ViewModel 的数据与命令，ViewModel 通过依赖注入获取 Model 层服务。


## 二、调试开发模式（Engineer Mode）

调试模式是开发者日常使用的核心工作环境，需提供**完整的数据可视化**、**灵活的参数调节**和**强大的诊断工具**。

### 2.1 整体布局

调试模式采用**多面板可拖拽布局**，参考专业 IDE 或 DAW 软件的窗口管理方式：

```
┌──────────────────────────────────────────────────────────────────────┐
│  [主菜单栏]  文件 │ 仿真 │ 视图 │ 工具 │ 帮助                      │
│  ┌──────────────┐ ┌─────────────────────┐ ┌──────────────────────┐ │
│  │ 3D 场景面板   │ │ 超声影像面板        │ │ 示波器/曲线面板      │ │
│  │ (机械臂模型)   │ │ (实时超声图像)      │ │ ─── 接触力 ───     │ │
│  │               │ │                     │ │ ╱╲╱╲╱╲╱╲         │ │
│  │  TCP 坐标系   │ │                     │ │ ─── 扭矩 ───       │ │
│  │  规划路径线    │ │                     │ │ ╲╱╲╱╲╱╲╱         │ │
│  │  力矢量箭头    │ │                     │ │ ─── 位置偏差 ───    │ │
│  └──────────────┘ └─────────────────────┘ └──────────────────────┘ │
│  ┌─────────────────────────────────────────────────────────────────┐ │
│  │ 参数面板 │ PID: Kp [___] Ki [___] Kd [___] │ 速度 [___] │     │ │
│  │ 日志控制台 │ [Info] 10:00:01.234 力控状态正常                  │ │
│  └─────────────────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 核心面板详细设计

#### 2.2.1 3D 场景面板

**功能定位**：实时可视化机械臂运动学状态、扫查路径与力反馈信息。

| 渲染元素 | 说明 |
|----------|------|
| 机械臂 DH 模型 | 按真实尺寸渲染各连杆与关节 |
| TCP 坐标系 | 显示工具中心点的位置与姿态（XYZ 三轴） |
| 规划路径线 | 高亮显示预设扫查路径 |
| 实时轨迹 | 显示 TCP 实际运动轨迹（带透明度渐变） |
| 力矢量箭头 | 实时显示末端接触力的大小与方向 |
| 超声探头模型 | 显示探头姿态与扫查面朝向 |

**交互方式**：
- 鼠标左键拖拽：旋转视角
- 鼠标滚轮：缩放
- 鼠标中键拖拽：平移场景
- 右键点击机械臂部件：显示该部件实时参数

**技术选型建议**：可采用 **Helix Toolkit**（功能全面）或 **Veldrid**（高性能跨平台）实现。

#### 2.2.2 超声影像面板

**功能定位**：实时显示超声探头采集的图像数据。

| 特性 | 说明 |
|------|------|
| 刷新率 | 125Hz（与超声数据发布频率同步） |
| 图像格式 | 灰度图 / 伪彩图可切换 |
| 叠加信息 | 扫查深度标尺、增益值、当前帧号 |
| 冻结功能 | 支持单帧冻结，便于仔细观察 |

**性能要求**：使用 `WriteableBitmap` 直接操作像素内存，避免高频创建新对象导致 GC 压力。

#### 2.2.3 示波器/曲线面板

**功能定位**：实时绘制关键物理量的时域曲线，用于调参与故障诊断。

| 曲线通道 | 颜色 | 说明 |
|----------|------|------|
| 接触力 (Fx/Fy/Fz) | 红/绿/蓝 | 三轴力传感器数据 |
| 扭矩 (Tx/Ty/Tz) | 橙/紫/青 | 三轴扭矩数据 |
| TCP 位置偏差 | 黄色 | 实际位置与规划位置的偏差 |
| 超声增益 | 白色 | 当前超声增益值 |

**交互功能**：
- 曲线缩放（框选放大 / 滚轮缩放）
- 游标测量（显示光标处数值与时间）
- 通道显隐切换
- 导出当前曲线数据为 CSV

#### 2.2.4 参数面板

**功能定位**：在线调节仿真与控制参数，支持**热加载**（修改立即生效，无需重启）。

| 参数组 | 参数项 | 取值范围 |
|--------|--------|----------|
| PID 控制 | Kp / Ki / Kd | 浮点数，可调 |
| 运动控制 | 扫查速度 / 加速度 | 0.1~100 mm/s |
| 力控 | 目标接触力 / 力控刚度 | 0~50 N |
| 超声 | 增益 / 深度 / 焦点位置 | 依超声设备而定 |
| 仿真 | 物理步长 / 迭代次数 | 不建议运行时修改 |

**交互方式**：
- 数值输入框 + 步进按钮
- 滑块（带当前值显示）
- 参数预设方案（快速加载一组参数）

#### 2.2.5 日志控制台

**功能定位**：分级显示系统运行日志，关联时间戳，便于问题追溯。

| 日志级别 | 颜色 | 用途 |
|----------|------|------|
| Debug | 灰色 | 详细调试信息（默认折叠） |
| Info | 白色 | 常规运行信息 |
| Warning | 黄色 | 警告（如力控超限） |
| Error | 红色 | 错误（如通信中断） |

**交互功能**：
- 级别过滤（按复选框筛选显示级别）
- 关键词搜索
- 日志导出（TXT / CSV）
- 自动滚动（可开关）

### 2.3 Avalonia 开发者工具集成

Avalonia 内置了 DevTools 调试窗口，可在 DEBUG 模式下通过 `AttachDevTools()` 方法启用：

```csharp
#if DEBUG
if (attachDevTools) {
    this.AttachDevTools();
}
#endif
```

默认按 **F12** 打开 DevTools，提供以下调试能力：

| 调试面板 | 功能 |
|----------|------|
| **逻辑树/视觉树** | 查看窗口控件树结构，选中控件查看属性 |
| **属性面板** | 快速检查和编辑控件属性（支持正则搜索） |
| **布局面板** | 检查和编辑 Margin、Border、Padding 等布局属性 |
| **样式面板** | 查看样式值及其来源，支持样式快照（Alt+S） |
| **事件面板** | 跟踪路由事件的传播路径 |

**热键**：`Ctrl+Shift`（检查指针指向的控件）、`F8`（截图选中控件）。

### 2.4 记录与回放模块

#### 2.4.1 数据记录

| 模式 | 说明 |
|------|------|
| **手动记录** | 点击“开始记录”后录制，点击“停止”结束 |
| **触发式记录** | 设定触发条件（如力超限），自动记录触发前后指定时长数据 |
| **循环缓存** | 类似行车记录仪，持续缓存最近 N 秒数据，按需保存 |

**记录内容**：
- 超声影像（带时间戳）
- 机械臂位姿（6D 姿态）
- 力/扭矩数据（6 维）
- 控制指令与状态

#### 2.4.2 数据回放

```
┌──────────────────────────────────────────────────────────────────────┐
│  ┌─────────────────────┐ ┌─────────────────────────────────────────┐ │
│  │ 超声影像（回放）      │ │ 同步数据曲线（力/扭矩/位置）            │ │
│  │                     │ │  ╱╲╱╲╱╲╱╲                            │ │
│  │  帧号: 00321/12000  │ │                                         │ │
│  └─────────────────────┘ └─────────────────────────────────────────┘ │
│  ◄══════●══════════════════════════════►  00:03:21 / 00:12:45      │
│  [◄◄] [►] [►►]  速度: [1.0x ▼]  [A] [B] 循环  [导出]             │
└──────────────────────────────────────────────────────────────────────┘
```

**核心功能**：
- 时间轴滑块拖拽跳转
- 播放/暂停/步进（单帧/多帧）
- 播放速度调节（0.1x ~ 2.0x）
- A/B 循环标记（便于反复分析特定区间）
- **双轨联动**：超声影像与数据曲线同步播放
- 导出回放片段（视频 + 数据）


## 三、临床应用模式（Operator Mode）

临床应用模式面向超声医生/技师，设计目标是**极简、安全、触控友好**。界面仅暴露扫查操作必需的控件，所有调试入口默认隐藏。

### 3.1 整体布局

```
┌─────────────────────────────────────────────────────────────────────┐
│  [状态栏]  ● 系统就绪  ● 机械臂已连接  ● 超声已连接  ● 力控正常   │
│  ┌─────────────────────────────────────────────────────────────────┐ │
│  │                                                                 │ │
│  │              超声影像区域（占据约 80% 屏幕）                    │ │
│  │                                                                 │ │
│  │                                                                 │ │
│  └─────────────────────────────────────────────────────────────────┘ │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────────────┐ │
│  │ 患者信息      │  │ 扫查进度     │  │  [ ▶ 开始 ] [ ⏸ 暂停 ]  │ │
│  │ 姓名: 张 XX   │  │ ████████░░  │  │  [ ⏹ 停止 ]              │ │
│  │ ID: 20260701  │  │ 扫查进度 65% │  │  状态: 扫查中            │ │
│  │ 部位: 腹部    │  │ 剩余 02:30  │  │                           │ │
│  └──────────────┘  └──────────────┘  └──────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.2 核心控件设计

| 控件 | 实现要点 |
|------|----------|
| **超声影像** | 全屏展示优先，使用 `WriteableBitmap` 高频更新（125Hz） |
| **状态指示器** | 红/黄/绿三色圆点，仅显示“就绪/警告/异常”三种状态 |
| **患者信息栏** | 极简显示姓名、ID、扫查部位，仅用于核对 |
| **扫查进度条** | 显示当前扫查进度百分比与剩余时间 |
| **控制按钮** | 开始/暂停需**长按确认**（防误触）；急停为物理按钮 |

### 3.3 交互限制

- **键盘**：屏蔽除急停外的绝大部分按键（通过 `PreviewKeyDown` 事件处理）
- **右键菜单**：全局禁用 `ContextMenu`
- **全屏模式**：`WindowState="FullScreen"`，`WindowDecorations="False"`
- **超时锁定**：空闲超过设定时间自动锁定屏幕，需重新验证身份

### 3.4 模式切换暗门

为方便开发者在临床现场跟台调试，设计**暗门切换机制**（不暴露给临床用户）：

- 在临床界面**左上角 Logo 处连续双击鼠标左键** + **同时按下键盘组合键**（如 `Ctrl+Shift+Alt+D`）
- 触发后在屏幕右侧**滑出一个半透明悬浮调试面板**（Overlay）
- 调试面板显示实时内部变量与下发指令入口，不遮挡主影像
- 关闭面板即恢复纯净临床态


## 四、共用组件与设计规范

### 4.1 主题与样式

系统支持**深色/浅色主题切换**，通过 `Application.Current.RequestedThemeVariant` 控制：

```csharp
Application.Current!.RequestedThemeVariant = ThemeVariant.Dark;
```

- **临床模式**：默认使用浅色主题，营造明亮、洁净的医疗环境
- **调试模式**：默认使用深色主题，减少视觉疲劳，突出数据可视化元素

样式管理建议：
- 使用 **样式类（Style Classes）** 而非内联属性
- 使用 **DynamicResource** 实现主题感知的资源引用
- 将样式放在独立 `Styles.axaml` 文件中统一管理

### 4.2 配色方案

| 场景 | 主色 | 辅色 | 强调色 |
|------|------|------|--------|
| 临床模式 | 白色/浅灰 (#FFFFFF/#F5F5F5) | 医疗蓝 (#1A73E8) | 绿色（正常）/ 红色（警告） |
| 调试模式 | 深灰 (#1E1E1E) | 中灰 (#3C3C3C) | 蓝色 (#007ACC) |

### 4.3 数据绑定规范

遵循 MVVM 模式的数据绑定规范：
- ViewModel 实现 `INotifyPropertyChanged`
- 使用 `CommunityToolkit.Mvvm` 的 `ObservableProperty` 和 `RelayCommand` 减少样板代码
- 启用**编译绑定（CompiledBindings）** 提升性能

### 4.4 性能规范

| 规范 | 说明 |
|------|------|
| UI 线程 | 仅执行布局、输入和绑定更新，不执行耗时操作 |
| 后台处理 | 仿真计算、数据采集、文件 I/O 均在后台线程执行 |
| 高频更新 | 使用 `WriteableBitmap` 更新图像，复用实例避免 GC |
| 数据传递 | 通过 `ConcurrentQueue` + `SemaphoreSlim` 实现线程安全的数据桥接 |
| 列表虚拟化 | 日志等长列表启用虚拟化 |
